# Third-party components and AI use

## AI assistance
- The web app (frontend, agent, database layer) was built by Simon with Claude Code (Anthropic).
- finance-core (score engine, buyer view, financing pack, lender marketplace) was built by Wojciech Pazoła with Claude.
- The in-app copilot runs on the Claude API (Anthropic). It only drafts; every action needs the owner's approval and is logged.
- The health score and financing figures are computed with transparent formulas in finance-core, not generated by AI.
